# FpsPlusPlusScanner

# To compile and run it
https://rust-lang.org/tools/install/
Install this and then run in the main directory of the source code
```
cargo build --release
```
it will build and output the exe in target/release/FpsPlusPlusScanner.exe
# Release
You can also just go to release section and run the actual executable though this scanner is very easy to evade and will only work on the samples i have gotten access to
