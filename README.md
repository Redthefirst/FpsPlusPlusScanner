# FpsPlusPlusScanner
Scans for the malware that infected people playground under the fps++++ mod i think

# To compile and run it
https://rust-lang.org/tools/install/
Install this and then run in the main directory of the source code
```
cargo build --release
```
it will build and output the exe in target/release/FpsPlusPlusScanner.exe
# Release
You can also just go to release section and run the actual executable though this scanner is very easy to evade and will only work on the samples i have gotten access to
# Usage
Open cmd and type the path of the scanner then type 2 to scan only people playground directory and then look for
Bad: loader signature found in C:\Program Files (x86)\Steam\steamapps\common\People Playground\Amy-Vanilla Tools-3468095876.dll Likely means your infected
This means your likely infected and you should delete that file
